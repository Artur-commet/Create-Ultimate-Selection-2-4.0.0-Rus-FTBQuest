# Руссификатор для Create Ultimate Selection 2

Этот русификатор предназначен для перевода квестов и описаний модпака [Create Ultimate Selection 2 (MC 1.21.1-4.0.0)](https://www.curseforge.com/minecraft/modpacks/create-ultimate-selection-2/files/7435136).  
Файл формата `.snbt`, который можно использовать для замены оригинальных текстов в моде.

⚠️ **Важно:**
- Перевод сделан ChatGPT, поэтому некоторые фразы могут быть неточными или непривычными.  
- Вкладки и части текста, которые не были переведены специально, остались на английском.  

---

## Установка
1. Перенесите файл `ru_ru.snbt` в папку `Create - Ultimate Selection 2 [Create Quests in 1.21.1]\config\ftbquests\quests\lang`.
2. Перезапустите игру/сервер или командой /ftbquests reload если включено использование команд.  
3. Проверьте корректность отображения текстов.  

---
## Ветка для исправлений
- Все найденные неточности и недопереведённые вкладки можно посмотреть или написать про неё в ветке [`ОБНАРУЖЕНО`](https://github.com/Artur-commet/Create-Ultimate-Selection-2-4.0.0-Rus-FTBQuest/tree/ОБНАРУЖЕНО)
